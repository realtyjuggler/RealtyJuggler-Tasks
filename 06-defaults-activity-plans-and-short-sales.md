# Chapter 6: Defaults, Activity Plans and Short Sales

## Default Records and Tasks

> Image: The Defaults icon, a dark brown egg shape with the label "Defaults" beneath it.

RealtyJuggler lets you set default values for your Prospect, Buyer, Listing, Buy Side Closing and Sell Side Closing records. The default values are used whenever you create a new record or transfer an existing one. Edit and view them at Main:Settings:Defaults.

Click the type of record you want to edit (Prospect, Buyer, Listing, Buy Side Closing, Sell Side Closing or Rental). Tabs appear on the left of the screen that let you edit the Parties, Contingencies, Tasks, Promotions and other particulars for that default record.

> Image: Screenshot of a default record editor. Buttons are "Done", "New Party" and "Delete Default Record". The left tab list shows Parties (9) selected, Contingencies (1), Documents (1) and Tasks. The party list has columns Role, Name, Phone/Email and Last Contact, with roles Buyer (green dot), Seller, Buyer Agent, Buyer Mortgage, Home Inspection Inspector, Insurance, Listing Agent, Settlement/Escrow for and Title Company. Links read "Download Parties" and "Tutorial 18".

RealtyJuggler has a fairly minimal set of defaults, so you will probably want to put together your own defaults to suit your region and your way of working. For parties, add any inspection parties you commonly need, such as Radon and Septic. The Contingencies tab is a great way to set up default contingencies you normally expect, such as Mortgage, Termite and Inspection. Not all tabs are available for all record types, but the available tabs match those of a record of that type.

You can also put together a default set of tasks by clicking the "Tasks" tab and creating tasks. These tasks can have a due date based on the creation date of the record (Start Date) or on another date, such as the Contract Date or Closing Date.

Use the other default tabs first and use Tasks for things that do not fit within the other tabs. For example, if you have specific promotions you do with all your Listing records, such as CraigsList, specific web sites or virtual walkthroughs, set up default Promotions to track them. That information is then tracked most easily, and Automatic tasks remind you to do the items on your Promotions list.

Similarly, if you normally need to contact specific people relating to your deals, such as for a mortgage or an inspection, add default parties and contingencies.

Every Party has a "Contact again in __ days" field. If you fill it in with a number in your default record, an Automatic Task reminds you to contact that party.

There are always tasks that fall between the cracks (or tabs, in this case), and the default Tasks are ideal for that.

There is no way to put together a DRIP sequence of letters using the Default records. If you need to do that, create a default task with a Task Description like "Apply DRIP sequence FSBO Prospect" to the record. Then, when you see that task in your task list, you can apply your DRIP sequence and click the task done.

If you have a Task Plan you want to apply to a default record, you can do that. Keep in mind that if you edit the task plan (at Main:Settings:Task Plans), your default record is not updated. You must also go into the default record (Main:Settings:Defaults) and edit it as well as your task plan.

## Mixing Letters and Tasks Together

If you have a task plan that includes a sequence of letters, go to Main:Settings:Mail Forms and create your DRIP letter sequence. Then add tasks to that letter sequence by clicking the "New DRIP Task" button on that screen. Make sure your tasks and your letters all have the same DRIP group. That is how RealtyJuggler knows they are bundled together. When you apply your DRIP letter sequence, any tasks associated with it are added to the tasks list for the record you apply the sequence to.

## Converting Old Activity Plans

If you have old activity plans you want to load into RealtyJuggler:

1. If your plan is primarily letters and emails with a few tasks sprinkled in, enter your plan in the Mail Forms section of RealtyJuggler at Main:Settings:Mail Forms. These kinds of plans are typically used for prospecting and keeping up with your Contacts.
2. If you want a set of default activities that you perform whenever you create a new Prospect, Buyer, Listing, Buy-Side Closing or Sell-Side Closing, go to Main:Settings:Defaults and modify the appropriate default records. The following steps describe how.
3. First, print your old Activity Plans. You should have a single plan for each of the default records described above. You can apply additional variations later, but for now focus on the default plans you want applied automatically. Break out your plans so that you separate tasks to be done before a ratified contract from tasks done after the contract is ratified. The first list goes into the Buyer and Listing records and the second lists go into the Buy-Side and Sell-Side Closing records.
4. First cross out any tasks that RealtyJuggler handles using Automatic tasks. Typically that eliminates around 80% of your old tasks.
5. Watch YouTube Video Tutorials 38 and 39. These videos explain how the AutoTasks work.
6. For your Listing record:
   1. Look for any tasks that relate to your promotions. These include open houses, caravans, production of flyers, postcards, entry of data into web sites, printing of any material and so on. Enter them in the Promotions tab for your Default Listing record. Since these are default values, just enter the descriptions. Automatic tasks prompt you to enter the scheduled dates for each promotion. For now, just enter the slots that will be filled in later. You can cross these old tasks off; they are handled using Automatic Tasks.
   2. Cross off any tasks about getting a key, installing a lockbox, putting up a yard sign, putting up riders, installing a brochure holder on the sign and populating it with flyers. These are handled using Automatic Tasks. If you have favorite riders (home warranty and so on) for your yard signs, enter them in the Sign section of the Listing default record. If you typically check your brochure box every so many days, enter that in the Default Sign tab and RealtyJuggler reminds you automatically.
   3. Identify tasks related to getting documents signed, sending documents to someone, and tracking expire dates for documents. This includes your listing agreement (and its expire date) and your agency agreement. Enter these documents in the Documents tab. You can use the Other document type for custom documents you name yourself. Eliminate those tasks from your old list.
   4. If you typically have your sellers purchase a home warranty, enter that document here.
   5. If you routinely check tax records for appraised value, back taxes, deed transfer fees and the like, enter a "Tax Records" document here.
   6. If there are disclosure documents you typically have signed, add them to the Documents tab.
   7. Identify all tasks that relate to any parties that might be related to your Listing. This includes a referral party (and any gifts to be sent, fees paid and thanks given to a referring agent). Enter this in the Parties tab. For the default record, enter the parties you anticipate. If you do not need a party for a particular deal, you can delete that party from the deal record. Listing records typically have few parties, since you do not need the extra parties until you have a ratified contract and move to a Closing record.
   8. Place any tasks that relate to taking photos of the home or doing a video walkthrough into the "Promotions" tab inside your default Listing record.
   9. By now you have probably eliminated about 80% of your old Tasks. Enter the remaining tasks in the "Tasks" tab for the Default Listing record.
7. Now convert your old Action plan for a Buy Side Closing. Go to Main:Settings:Defaults and click the Buy Side Closing icon.
   1. Look at your old Action plan and find all the tasks that relate to parties. This may include a Referral party, possibly an Attorney. If you typically recommend a home warranty, add that here, as well as fire insurance party, title insurance, closing company and so on. Auto Tasks handle those dates for you.
   2. If you typically check with a particular party regularly, like a loan officer, enter the value in the "Contact every xx days" field for that party. Auto Tasks handle that, so you can eliminate those reminders from your old checklist.
   3. The Mortgage party has slots for the approval status and the expiration date.
   4. If you normally do inspections (termite, well, septic, radon), add an inspector party and name the kind of inspection (for example, termite). RealtyJuggler prompts you to schedule each inspection, wait for results and even track the expire date for the inspection (such as termite).
   5. Enter any contingencies typical for your buy-side deals in the Contingencies tab. This likely includes mortgage approval and one or more inspection contingencies. If you do short sales, you can add approval of Seller note-holder (YouTube Video Tutorial 33 shows how). You can eliminate all tasks relating to contingencies and their approval from your old list. AutoTasks handle those.
   6. Enter any documents typical for your buy-side closings in the Documents tab. This likely includes your purchase agreement, HOA/POA documents, power of attorney and so on. You can then eliminate any tasks relating to signing documents or tracking expiration dates for documents.
   7. Remove all tasks relating to scheduling (and attending) closing and walk-thru.
   8. Remove all tasks relating to updating the mailing address of the buyer once they have moved in.
   9. Remove all tasks regarding picking up the commission check.
   10. Remove all tasks relating to earnest money, scheduled earnest money and so on. These are handled automatically using the Escrow tab.
   11. Remove all tasks relating to calling the buyer after closing and sending a housewarming gift. Those are handled automatically. RealtyJuggler also automatically reminds you to contact your buyer on their closing anniversary.
   12. It is likely you have eliminated about 80% of your old tasks. Whatever remains can be added to the Tasks tab of your Buy-Side closing default record.

## Handling Short-Sales

A brief description of how to organize a Short Sale:

1. The Parties tab in both the Listings and Closings databases can track the first and second lien holder and any other parties you need. Create a new Party and select a Role of Seller Mortgage, Second Seller Loan or Third Seller Loan. Enter contact information, notes, payoff amount, loan # and a contact every xx days field.
2. The Documents tab in both the Listings and Closings databases can track all the documentation you have sent and received. It also lets you track specific notes about each document, its expire date, and who has seen and signed it.
3. The Contingencies tab in the Closing record can track what is required to close the deal. Enter a contingency for bank approval with a status of "Deal Blocker". There are likely additional deal-blocker contingencies to document (for example a second lien holder and BPO). Video Tutorial 33 explains how this works.
4. Use the Extra Status values available in the Listing and Closing record to describe where you are in the short-sale process. This lets you see the status of your deals at a glance in the summary view for both Listings and Closings. For example, if you are awaiting bank approval, add that status as an Extra Status value. More information is in Video Tutorial 33.
5. If you have a specific set of tasks for short-sales, create your own task plan and apply it to short-sale deals. Information on task plans is in Video Tutorial 19. Create a plan for the Listing record, a second plan for everything prior to approval by the bank, and a third plan for after the bank has given approval. The advantage of three plans is that you see only the tasks you need to complete to get to the next stage. There is no point in doing (or dwelling on) tasks that belong to later stages until you are ready for them.
6. The notes and contact every xx days fields are the best way to stay current with each party in a deal. Video Tutorial 44 shows how to create a touch-cycle. This is the perfect way to call the lien holder every few days to make sure the deal is progressing.
7. The Offers tab in the Listing record can track multiple simultaneous offers as well as stacking of offers.
8. If your Closing falls through, go back to the old Listing record, change its status to Active and continue with the active listing.
9. The Service Report tab lets you see all your notes, documents, parties and any other information relating to the deal in one summary view.
